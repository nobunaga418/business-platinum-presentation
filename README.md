# PLATINUM / BUSINESS STUDIO

アメリカン・エキスプレスのビジネス・プラチナ・カードについて、法人経営者・個人事業主との商談を支援する日本語の非公式試作品です。American Expressとの提携・承認関係はありません。

## 開発

Node.js 22以上を推奨（検証：24.22.1）。外部APIやシークレットは不要です。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

実ブラウザーの機能テスト：開発サーバーを起動した状態で `node tests/browser.mjs`。Chromiumは `/usr/bin/chromium` を使用します。390px・1440px幅でサービス絞り込み、業種切り替え、計算、スライド、リセット、ストレージ非使用、再読み込み時の消去、横はみ出しを検証します。スクリーンショットは `/tmp/platinum-*.png` に出力します。

## 機能

- サービス・補償の確認項目一覧、カテゴリ絞り込み、条件の展開
- 5業種の一般的な課題と提案の切り口
- ユーザーが入力した仮定に基づく年間価値試算
- 選択した業種・入力値を反映する5枚の商談スライド（左右キー、Escape対応）
- モバイル対応、キーボード操作、入力欄ラベル、減らす動きの設定への対応

## 情報の確認状況

参照先： https://www.americanexpress.com/ja-jp/credit-cards/business-platinum-card/

2026年11月14日、開発環境から公式サイトの本文取得を試みましたが、アクセス制限（403）により取得できませんでした。サービス項目は**提供を確認済みの網羅的な特典一覧ではなく、商談前に確認するための項目**です。公式情報の検証は未完了です。提供状況・名称・対象者・登録・決済条件・対象施設・免責・限度額などを公式の最新規約で確認してから利用してください。年会費、補償額、入会キャンペーンの数値は掲載していません。

計算式：年間出張回数 × 1回あたりの想定価値 ＋ 月間削減時間 × 12 × 時間単価。参考純額はこの合計から入力年会費を差し引きます。初期値の0は年会費の事実を表しません。ポイント・税効果・保険金は算入しません。想定価値の二重計上に注意し、費用回収・便益を保証するものとして扱わないでください。

## プライバシー・構成

Vite + Vanilla JavaScriptの静的アプリ。アプリにサーバーAPI、アナリティクス、Cookie、localStorage、sessionStorage、外部フォント、外部画像はありません。会社名・氏名の入力欄もありません。入力はメモリ内だけで扱い、再読み込みで消去します。公式リンクを開いた後はリンク先のポリシーが適用されます。装飾カードはCSSの独自コンセプトで、実券面ではありません。

`npm run build` の `dist/` を静的ホスティングできます。環境公開や本番へのデプロイはこの変更の対象外です。
